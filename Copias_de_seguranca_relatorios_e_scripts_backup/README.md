# Cópias de segurança — relatórios e scripts backup

Este diretório funciona como uma área de downloads e recuperação do projeto **GrandCross Local**, organizada no próprio GitHub.

## Organização
- `relatorios/`: relatórios e resultados técnicos por intervalos de passos.
- `scripts/`: scripts próprios de análise reproduzível.
- `evidencias/`: resultados estruturados sem binários proprietários.
- `logs/`: registros sanitizados de testes.

## Primeiro pacote: PASSOS 1170–1174
- [Relatório](relatorios/PASSOS_1170_1174_Relatorio.md)
- [Script reproduzível](scripts/grandcross_rmi_1170_1174.py)
- Os dados estruturados e logs serão adicionados conforme as permissões de publicação permitirem.

## Política
Somente resultados de pesquisa, código próprio e evidências sem credenciais. Não publicar DLLs, metadados originais, tokens ou capturas privadas.
Backups somente contam como concluídos após confirmação de commit pelo GitHub. O código original usa os arquivos de entrada presentes no laboratório e não roda isoladamente sem eles.
